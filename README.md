## Advantages
- Smooth Animations: Employs LayoutAnimation for animations, which are executed natively on Android and iOS and result in smooth transitions.
- Flexible Interaction Control: Offers the ability to label particular areas of the screen as interactive or non-interactive during the tutorial to ensure better user experience.
- Multiple Highlighting: Allows multiple highlighting on the screen simultaneously for a single step for complete guidance.
- Customizable Overlay: Provides a fully customizable overlay, with the option to retrieve the position of the highlighted area, so tutorial elements can be properly placed.

## Disadvantages
- Insufficient Documentation: As the library is quite young and also currently under development, there could be a lack of adequate documentation provided, thereby creating implementation issues.
- Development Status: The library is currently in beta, and this may imply there is a possibility of encountering bugs or unfinished features.
- Expo Compatibility: Although compatible with Expo, some of its advanced native capabilities might not be fully supported depending on Expo's limitations.
